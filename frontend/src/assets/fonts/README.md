# Self-hosted web fonts

The frontend bundles only these four static WOFF2 files:

- Inter Latin: 400 and 600
- Noto Sans SC Simplified Chinese: 400 and 600

They were sourced from Fontsource packages `@fontsource/inter@5.3.0` and
`@fontsource/noto-sans-sc@5.3.0`. Both font families are distributed under the
SIL Open Font License 1.1; the corresponding license texts are stored in this
directory.
